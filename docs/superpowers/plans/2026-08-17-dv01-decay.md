# DV01, decay e resultado — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Calcular PU, DV01, decay e resultado do estoque da dívida por papel, em cada fim de mês desde 2010, e permitir o cálculo pontual até uma data-alvo escolhida.

**Architecture:** Um motor de precificação portado do código em uso na mesa, apoiado num calendário de dias úteis com índice pré-computado; a coleta da Bloomberg escreve em `data/raw/` e a interpretação lê de disco, igual à camada de dados existente; o painel de DV por papel é persistido porque as entregas 3 e 5 vão consumi-lo, e o cálculo pontual é um comando, não uma tabela.

**Tech Stack:** Python 3.12, pandas, openpyxl, xlrd, matplotlib, pytest, blpapi (só na coleta).

**Spec:** `docs/superpowers/specs/2026-08-17-dv01-decay-design.md`
**Convenções:** `docs/convencoes-dv.md` — leitura obrigatória antes da Tarefa 2.

## Global Constraints

- **Bibliotecas:** `pandas`, `openpyxl`, `xlrd`, `matplotlib`, `pytest`. Mais `blpapi` **exclusivamente** em `fetch_bloomberg.py` — nenhum outro módulo pode importá-lo, nem no topo nem dentro de função.
- **Base de cálculo em D+0.** O mercado liquida em D+1; o teste contra a Bloomberg aplica o deslocamento, a produção não. Não "corrija" a produção para o teste passar.
- **Data de posição é o último dia útil do mês.** 61 das 198 datas do painel diferem do último dia corrido.
- **31/12 é dia útil.** O arquivo da Anbima não o lista e nós não o acrescentamos.
- **Percentuais como percentual** (`13.5` = 13,5%), não fração. A taxa entra em decimal só dentro da precificação.
- **Ausente é vazio, nunca zero.** Para LFT o `dv_unitario` é **vazio**, não zero.
- **A truncagem faz parte do DV**: diferença de dois PUs truncados, deliberadamente.
- **Sinal:** `PU(taxa + 1bp) − PU(taxa)`, negativo para título. Negativo = mercado perde.
- **Arquivos `.py` inteiramente ASCII**, comentários e docstrings inclusive. Literais de dado mantêm acento (`"NTN-B"`, `"Índices de Preços"`). Os `.md` usam acentuação normal.
- **`data/raw/` é imutável.**
- **Escopo do DV01:** LTN, NTN-F, NTN-B. A LFT tem só o financeiro. NTN-C, NTN-B Principal, RendA+ e EducA+ ficam fora.
- **Invocação exige `PYTHONPATH=src`.**

```python
"""Calendario de dias uteis do mercado brasileiro.

Duas responsabilidades: ler o arquivo oficial de feriados da Anbima, e
contar dias uteis em tempo constante.

A contagem por indice existe por necessidade de escala. O codigo em uso na
mesa conta dia a dia, o que custa 762 ms numa NTN-B 2060 -- e o painel tem
milhares de pares papel-data, cada um exigindo dois precos. Com o indice
acumulado, du() vira uma subtracao.

O indice nao pode mudar nenhum numero em relacao a contagem dia a dia. O
teste guarda uma implementacao ingenua como oraculo e compara as duas.
"""
import calendar as _calendar
import datetime
from datetime import date, timedelta
from pathlib import Path

import pandas as pd

from . import config

# O painel comeca em 2010 e ha NTN-B vencendo em 2060; o arquivo da
# Anbima cobre 2001 a 2099. Indexamos a janela inteira, uma vez.
_INICIO = date(2000, 1, 1)
_FIM = date(2099, 12, 31)


def carregar_feriados(caminho=None):
    """Le o arquivo da Anbima e devolve o conjunto de datas de feriado.

    O arquivo tem tres colunas (Data, Dia da Semana, Feriado) e termina
    com notas de rodape, que sao descartadas por nao serem data.
    """
    caminho = Path(caminho) if caminho else config.ANBIMA_DIR / config.ARQUIVO_FERIADOS
    if not caminho.exists():
        raise FileNotFoundError(
            f"calendario de feriados nao encontrado em {caminho}; baixe de "
            f"anbima.com.br/feriados/arqs/feriados_nacionais.xls e coloque "
            f"nessa pasta (veja docs/como-baixar.md)"
        )
    bruto = pd.read_excel(caminho, header=0)
    datas = pd.to_datetime(bruto["Data"], errors="coerce")
    return set(datas.dropna().dt.date)


class Calendario:
    """Conta dias uteis em tempo constante.

    `du(a, b)` reproduz exatamente a contagem dia a dia: o numero de dias
    uteis no intervalo fechado [a, b], menos um. Com a e b uteis, e o
    numero de dias uteis decorridos entre eles.
    """

    def __init__(self, feriados):
        self.feriados = set(feriados)
        self._idx = {}
        n = 0
        d = _INICIO
        um_dia = timedelta(days=1)
        while d <= _FIM:
            if d.weekday() < 5 and d not in self.feriados:
                n += 1
            self._idx[d] = n          # dias uteis em [_INICIO, d], inclusive
            d += um_dia

    def eh_dia_util(self, d):
        return d.weekday() < 5 and d not in self.feriados

    def _acumulado(self, d):
        try:
            return self._idx[d]
        except KeyError:
            raise ValueError(
                f"data {d} fora do calendario carregado "
                f"({_INICIO} a {_FIM})"
            ) from None

    def du(self, a, b):
        if b < a:
            a, b = b, a
        # dias uteis em [a, b] = acumulado(b) - acumulado(a) + (1 se a e util)
        n = self._acumulado(b) - self._acumulado(a) + (1 if self.eh_dia_util(a) else 0)
        return n - 1

    def mover(self, d, k):
        """Anda k dias uteis a partir de d. Sempre sai da data inicial."""
        if k == 0:
            return d
        passo = 1 if k > 0 else -1
        um_dia = timedelta(days=passo)
        restante = abs(k)
        while restante:
            d += um_dia
            while not self.eh_dia_util(d):
                d += um_dia
            restante -= 1
        return d

    def ajustar_vencimento(self, d):
        """Leva a data para o dia util efetivo de pagamento.

        Reproduz o comportamento do codigo da mesa: recua um dia util e
        avanca um. Um dia util devolve ele mesmo; um feriado ou fim de
        semana devolve o primeiro dia util seguinte.
        """
        return self.mover(self.mover(d, -1), 1)

    def ultimo_dia_util_do_mes(self, d):
        ultimo = date(d.year, d.month, _calendar.monthrange(d.year, d.month)[1])
        while not self.eh_dia_util(ultimo):
            ultimo -= timedelta(days=1)
        return ultimo


_PADRAO = None


def padrao():
    """Instancia unica sobre o arquivo oficial; o indice custa a montar."""
    global _PADRAO
    if _PADRAO is None:
        _PADRAO = Calendario(carregar_feriados())
    return _PADRAO
```

```python
"""Preco unitario e DV01 dos titulos publicos federais.

Portado do codigo em uso na mesa, validado contra o PX_DIRTY_MID da
Bloomberg em 438 pares papel-data entre 2020 e 2026 -- exato em todas as
comparacoes de NTN-F e NTN-B. Ver docs/convencoes-dv.md.

A taxa entra em DECIMAL (0.135 = 13,5%); quem chama converte.

Tres convencoes que parecem detalhe e nao sao:

  A truncagem esta dentro do DV de proposito. O PU truncado e o preco
  negociavel, entao a diferenca entre dois truncados e o que de fato se
  ganha ou perde quando a taxa anda 1 bp. Nao "melhore" isso calculando o
  DV com PUs cheios.

  O sinal e PU(taxa + 1bp) - PU(taxa), negativo para titulo. Multiplicado
  pela posicao, da direto o dinheiro perdido num choque de alta.

  A LFT devolve None no DV, nao zero: e decisao de modelagem do projeto,
  e "nao se aplica" precisa ser distinguivel de "risco nulo medido".
"""
import math

_UM_BP = 0.0001

# Cupom semestral: 1000 * ((1,10)^0,5 - 1) = 48,8088 na NTN-F;
# 100 * ((1,06)^0,5 - 1) = 2,9563 na NTN-B, sobre principal de 100.
_CUPOM_NTNF = 1000 * ((1.10 ** 0.5) - 1)
_CUPOM_NTNB = 100 * ((1.06 ** 0.5) - 1)


def _truncar(x, casas):
    fator = 10 ** casas
    return math.trunc(x * fator) / fator


def _meses_antes(d, meses):
    """Recua `meses` no calendario, sem estourar o fim do mes."""
    import calendar as _c
    from datetime import date as _date
    m = d.month - 1 - meses
    ano = d.year + m // 12
    m = m % 12 + 1
    return _date(ano, m, min(d.day, _c.monthrange(ano, m)[1]))


def pu_ltn(cal, d0, vencimento, taxa):
    """Prefixado sem cupom: 1000 descontado ate o vencimento."""
    venc = cal.ajustar_vencimento(vencimento)
    if d0 >= venc:
        return 0.0
    return _truncar(1000 / ((1 + taxa) ** (cal.du(d0, venc) / 252)), 6)


def pu_lft(cal, d0, vencimento, taxa, vna):
    """Pos-fixada: cotacao sobre o agio, aplicada ao VNA da Selic."""
    venc = cal.ajustar_vencimento(vencimento)
    if d0 >= venc:
        return 0.0
    cotacao = _truncar(100 / ((1 + taxa) ** (cal.du(d0, venc) / 252)), 4)
    return _truncar(cotacao * vna / 100, 6)


def pu_ntnf(cal, d0, vencimento, taxa):
    """Prefixado com cupom semestral. Os cupons caem no dia 1."""
    from datetime import date as _date
    venc = cal.ajustar_vencimento(vencimento)
    cupom = venc
    soma = 0.0
    while cupom > d0:
        principal = 1000 if cupom == venc else 0
        fluxo = round(_CUPOM_NTNF + principal, 5)
        soma += fluxo / ((1 + taxa) ** (cal.du(d0, cupom) / 252))
        anterior = _meses_antes(cupom, 6)
        cupom = cal.ajustar_vencimento(_date(anterior.year, anterior.month, 1))
    return _truncar(soma, 6)


def pu_ntnb(cal, d0, vencimento, taxa, vna):
    """Indexada ao IPCA, cupom semestral. Os cupons caem no dia 15.

    A cotacao e truncada em 4 casas antes de multiplicar pelo VNA, e o
    resultado em 6 -- e a convencao do mercado, nao um arredondamento
    nosso.
    """
    from datetime import date as _date
    venc = cal.ajustar_vencimento(vencimento)
    cupom = venc
    cotacao = 0.0
    while cupom > d0:
        principal = 100 if cupom == venc else 0
        fluxo = round(_CUPOM_NTNB + principal, 6)
        cotacao += fluxo / ((1 + taxa) ** (cal.du(d0, cupom) / 252))
        anterior = _meses_antes(cupom, 6)
        cupom = cal.ajustar_vencimento(_date(anterior.year, anterior.month, 15))
    return _truncar(_truncar(cotacao, 4) / 100 * vna, 6)


_INDEXADOS = {"NTN-B", "LFT"}


def pu(cal, titulo, d0, vencimento, taxa, vna=None):
    """Despacha para a formula do titulo. Taxa em decimal."""
    if titulo in _INDEXADOS and vna is None:
        raise ValueError(f"{titulo} exige VNA e nenhum foi informado")
    if titulo == "LTN":
        return pu_ltn(cal, d0, vencimento, taxa)
    if titulo == "NTN-F":
        return pu_ntnf(cal, d0, vencimento, taxa)
    if titulo == "NTN-B":
        return pu_ntnb(cal, d0, vencimento, taxa, vna)
    if titulo == "LFT":
        return pu_lft(cal, d0, vencimento, taxa, vna)
    raise ValueError(
        f"titulo sem formula de precificacao: {titulo!r}. "
        f"O escopo do projeto e LTN, NTN-F, NTN-B e LFT."
    )


def dv(cal, titulo, d0, vencimento, taxa, vna=None):
    """Variacao do PU para +1 bp na taxa. Negativo para titulo.

    Devolve None para LFT: por decisao de modelagem ela nao entra no
    DV01 do projeto, e None mantem isso distinguivel de zero.
    """
    if titulo == "LFT":
        return None
    return (pu(cal, titulo, d0, vencimento, taxa + _UM_BP, vna)
            - pu(cal, titulo, d0, vencimento, taxa, vna))
```

```python
"""Converte os brutos da Bloomberg nas tabelas canonicas.

A coleta e incremental por desenho: cada puxada grava um arquivo novo em
data/raw/bloomberg/ e nada e sobrescrito. Por isso o parser le TODOS os
arquivos de cada tipo, concatena, e em caso de repeticao fica com a
ultima ocorrencia -- que e a puxada mais recente.

As duas fontes trazem a data em convencoes diferentes: a de taxas ja vem
no ultimo dia util do mes (e o que a periodicidade mensal da Bloomberg
devolve), e a de VNA vem no ultimo dia corrido, porque foi assim que o
override de SETTLE_DT foi pedido. Verificado durante o design que o VNA e
identico nos dois dias, porque nao acumula em dia nao util. As duas sao
normalizadas para o ultimo dia util, que e a chave de juncao do projeto.
"""
from pathlib import Path

import pandas as pd

from . import calendario, config


def _ler_todos(padrao, diretorio=None):
    diretorio = Path(diretorio) if diretorio else config.BLOOMBERG_DIR
    arquivos = sorted(diretorio.glob(padrao))
    if not arquivos:
        raise FileNotFoundError(
            f"nenhum arquivo {padrao!r} em {diretorio}; rode a coleta com "
            f"'python -m tesouro.fetch_bloomberg' ou coloque a exportacao "
            f"do BDH nessa pasta (veja docs/como-baixar.md)"
        )
    return pd.concat([pd.read_csv(a) for a in arquivos], ignore_index=True)


def parse_taxas(diretorio=None):
    """Taxa indicativa Anbima por papel e fim de mes, em percentual."""
    cal = calendario.padrao()
    df = _ler_todos("bbg_taxas_*.csv", diretorio)
    df["data"] = pd.to_datetime(df["data"]).dt.date.map(cal.ultimo_dia_util_do_mes)
    df["vencimento"] = pd.to_datetime(df["vencimento"]).dt.date
    df = df.rename(columns={"yld_ytm_mid": "taxa_pct"})
    df = df.drop_duplicates(subset=["data", "isin"], keep="last")
    return df[["data", "isin", "titulo", "vencimento", "taxa_pct"]].sort_values(
        ["data", "titulo", "isin"]
    ).reset_index(drop=True)


def parse_vna(diretorio=None):
    """VNA por indice e fim de mes, em reais.

    O VNA e por indice, nao por papel: verificado que o valor e identico
    entre papeis diferentes na mesma data, em todas as datas do painel.
    """
    cal = calendario.padrao()
    df = _ler_todos("bbg_vna_*.csv", diretorio)
    df["data"] = pd.to_datetime(df["data"]).dt.date.map(cal.ultimo_dia_util_do_mes)
    df = df.drop_duplicates(subset=["data", "indice"], keep="last")
    return df[["data", "indice", "vna"]].sort_values(
        ["data", "indice"]
    ).reset_index(drop=True)


def gravar():
    config.PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    for nome, df in (("taxa_por_papel", parse_taxas()), ("vna", parse_vna())):
        saida = config.PROCESSED_DIR / f"{nome}.csv"
        df.to_csv(saida, index=False, encoding="utf-8")
        print(f"gravado: {saida} ({len(df)} linhas)")


if __name__ == "__main__":
    gravar()
```

```python
"""Coleta taxa e VNA na Bloomberg.

Unico modulo do projeto que fala com o terminal, e o import de blpapi fica
DENTRO da funcao de coleta: assim o resto roda em maquina sem Bloomberg,
que e o cenario do ambiente de destino.

Contrato de dados em docs/convencoes-dv.md. Dois pontos que o codigo
respeita e que nao sao obvios:

  A fonte @ANDE e obrigatoria no identificador do papel. Sem ela a taxa
  vem de outra origem; na ponta curta a diferenca chega a alguns bp.

  SETTLE_DT muda a data de LIQUIDACAO, nao a data do mercado. Serve para o
  VNA, que e funcao deterministica da data. NAO serve para taxa: usa-lo
  ali devolve a taxa de hoje liquidando na data pedida, o que no fim de
  2024 da 135 bp de erro.

A coleta e incremental: cada execucao grava um arquivo novo, nomeado pelo
periodo coberto, e nada e sobrescrito.
"""
import csv
from pathlib import Path

import pandas as pd

from . import calendario, config

TITULOS = ("LTN", "NTN-F", "NTN-B", "LFT")
CAMPO_TAXA = "YLD_YTM_MID"
# O preco nao entra em calculo nenhum: serve de referencia independente
# para o teste de coerencia. Ver docs/convencoes-dv.md sobre o D+1.
CAMPO_PRECO = "PX_DIRTY_MID"
CAMPO_VNA = {"NTN-B": ("IDX_RATIO", "IPCA"), "LFT": ("ACCUMULATED_SELIC", "SELIC")}
_HOST, _PORTA = "localhost", 8194


def _estoque():
    caminho = config.PROCESSED_DIR / "estoque_titulos_vencimento.csv"
    if not caminho.exists():
        raise FileNotFoundError(
            f"{caminho} nao existe; rode a camada de dados antes "
            f"('python -m tesouro.pipeline --sem-coleta')"
        )
    df = pd.read_csv(caminho, parse_dates=["data", "vencimento"])
    return df[df["quantidade_mil"].fillna(0) > 0]


def papeis_do_estoque():
    """Papeis do escopo, com a janela em que tiveram estoque."""
    e = _estoque()
    e = e[e["titulo"].isin(TITULOS)]
    p = (e.groupby(["isin", "titulo", "vencimento"])["data"]
           .agg(primeira="min", ultima="max").reset_index())
    p["vencimento"] = p["vencimento"].dt.date
    p["primeira"] = p["primeira"].dt.date
    p["ultima"] = p["ultima"].dt.date
    return p.sort_values(["titulo", "vencimento"]).reset_index(drop=True)


def datas_do_painel():
    """Os fins de mes do estoque, mapeados para o ultimo dia util."""
    cal = calendario.padrao()
    e = _estoque()
    return sorted({cal.ultimo_dia_util_do_mes(d) for d in e["data"].dt.date})


def _sessao():
    import blpapi
    opcoes = blpapi.SessionOptions()
    opcoes.setServerHost(_HOST)
    opcoes.setServerPort(_PORTA)
    sessao = blpapi.Session(opcoes)
    if not sessao.start() or not sessao.openService("//blp/refdata"):
        raise ConnectionError(
            "nao foi possivel falar com o terminal Bloomberg. Confira se ele "
            "esta aberto e logado nesta maquina. Sem terminal, exporte por "
            "BDH e coloque o CSV em data/raw/bloomberg/ (docs/como-baixar.md)"
        )
    return blpapi, sessao


def _historico(blpapi, sessao, servico, isin, campo, inicio, fim):
    req = servico.createRequest("HistoricalDataRequest")
    req.getElement("securities").appendValue(f"/isin/{isin}@ANDE Govt")
    req.getElement("fields").appendValue(campo)
    req.set("startDate", inicio.strftime("%Y%m%d"))
    req.set("endDate", fim.strftime("%Y%m%d"))
    req.set("periodicitySelection", "MONTHLY")
    sessao.sendRequest(req)
    pontos = []
    while True:
        evento = sessao.nextEvent(30000)
        for msg in evento:
            if not msg.hasElement("securityData"):
                continue
            dados = msg.getElement("securityData")
            if dados.hasElement("securityError"):
                return []
            campos = dados.getElement("fieldData")
            for i in range(campos.numValues()):
                ponto = campos.getValue(i)
                if ponto.hasElement(campo):
                    pontos.append((
                        pd.Timestamp(ponto.getElementAsDatetime("date")).date(),
                        ponto.getElementAsFloat(campo),
                    ))
        if evento.eventType() == blpapi.Event.RESPONSE:
            return pontos


def _referencia(blpapi, sessao, servico, isins, campo, settle):
    """Valor do campo com override de SETTLE_DT, para varios papeis."""
    req = servico.createRequest("ReferenceDataRequest")
    for isin in isins:
        req.getElement("securities").appendValue(f"/isin/{isin}@ANDE Govt")
    req.getElement("fields").appendValue(campo)
    override = req.getElement("overrides").appendElement()
    override.setElement("fieldId", "SETTLE_DT")
    override.setElement("value", settle.strftime("%Y%m%d"))
    sessao.sendRequest(req)
    valores = []
    while True:
        evento = sessao.nextEvent(30000)
        for msg in evento:
            if not msg.hasElement("securityData"):
                continue
            todos = msg.getElement("securityData")
            for i in range(todos.numValues()):
                dados = todos.getValue(i)
                if dados.hasElement("securityError"):
                    continue
                campos = dados.getElement("fieldData")
                if campos.hasElement(campo):
                    valores.append(campos.getElementAsFloat(campo))
        if evento.eventType() == blpapi.Event.RESPONSE:
            return valores


def baixar(destino=None):
    """Puxa taxa e VNA e grava dois CSVs. Devolve os dois caminhos."""
    destino = Path(destino) if destino else config.BLOOMBERG_DIR
    destino.mkdir(parents=True, exist_ok=True)
    blpapi, sessao = _sessao()
    servico = sessao.getService("//blp/refdata")
    try:
        papeis = papeis_do_estoque()
        datas = datas_do_painel()
        marca = f"{datas[0]:%Y-%m}_{datas[-1]:%Y-%m}"

        alvo_taxa = destino / f"bbg_taxas_ANDE_{marca}.csv"
        with open(alvo_taxa, "w", newline="", encoding="utf-8") as fh:
            escritor = csv.writer(fh)
            escritor.writerow(["isin", "titulo", "vencimento", "data", "yld_ytm_mid"])
            for p in papeis.itertuples(index=False):
                for data, valor in _historico(blpapi, sessao, servico, p.isin,
                                              CAMPO_TAXA, p.primeira, p.ultima):
                    escritor.writerow([p.isin, p.titulo, p.vencimento, data, valor])
        print(f"gravado: {alvo_taxa}")

        e = _estoque()
        alvo_vna = destino / f"bbg_vna_{marca}.csv"
        with open(alvo_vna, "w", newline="", encoding="utf-8") as fh:
            escritor = csv.writer(fh)
            escritor.writerow(["data", "indice", "campo", "fator", "vna",
                               "n_papeis", "divergencia"])
            for data in datas:
                mes = (data.year, data.month)
                for titulo, (campo, indice) in CAMPO_VNA.items():
                    vivos = e[(e["titulo"] == titulo)
                              & (e["data"].dt.year == mes[0])
                              & (e["data"].dt.month == mes[1])]["isin"].head(3).tolist()
                    if not vivos:
                        continue
                    valores = _referencia(blpapi, sessao, servico, vivos, campo, data)
                    if not valores:
                        continue
                    escritor.writerow([data, indice, campo, f"{valores[0]:.9f}",
                                       f"{valores[0] * 1000:.6f}", len(valores),
                                       f"{max(valores) - min(valores):.9f}"])
        print(f"gravado: {alvo_vna}")

        alvo_preco = destino / f"bbg_precos_ANDE_{marca}.csv"
        with open(alvo_preco, "w", newline="", encoding="utf-8") as fh:
            escritor = csv.writer(fh)
            escritor.writerow(["isin", "titulo", "data", "px_dirty_mid"])
            for p in papeis.itertuples(index=False):
                for data, valor in _historico(blpapi, sessao, servico, p.isin,
                                              CAMPO_PRECO, p.primeira, p.ultima):
                    escritor.writerow([p.isin, p.titulo, data, valor])
        print(f"gravado: {alvo_preco}")

        return alvo_taxa, alvo_vna, alvo_preco
    finally:
        sessao.stop()


if __name__ == "__main__":
    baixar()
```

```python
"""Painel de DV01 por papel, decay e calculo pontual.

O painel e persistido, e nao calculado sob demanda, porque as entregas 3
(analise de leiloes) e 5 (simulacao contra o PAF) vao consumi-lo. Tres
implementacoes independentes de DV que discordam entre si seria o pior
resultado possivel.

Unidades: quantidade_mil e o estoque em milhares de titulos; pu e
dv_unitario sao reais por titulo. Logo o financeiro e o DV da posicao,
em milhoes de reais, sao (valor por titulo) * quantidade_mil / 1000.
"""
import pandas as pd

from . import calendario, config, precificacao

TITULOS = ("LTN", "NTN-F", "NTN-B", "LFT")
_INDICE_DO_TITULO = {"NTN-B": "IPCA", "LFT": "SELIC"}

_COLUNAS = [
    "data", "isin", "titulo", "vencimento", "taxa_pct", "vna", "pu",
    "dv_unitario", "quantidade_mil", "dv_posicao_milhoes",
    "financeiro_calculado_milhoes",
]


def _ler(nome, **kw):
    caminho = config.PROCESSED_DIR / f"{nome}.csv"
    if not caminho.exists():
        raise FileNotFoundError(
            f"{caminho} nao existe. Rode a camada de dados e o parser da "
            f"Bloomberg antes: 'python -m tesouro.pipeline --sem-coleta'"
        )
    return pd.read_csv(caminho, **kw)


def _posicoes(cal):
    """Estoque do escopo, com a data ja no ultimo dia util do mes."""
    e = _ler("estoque_titulos_vencimento", parse_dates=["data", "vencimento"])
    e = e[(e["quantidade_mil"].fillna(0) > 0) & e["titulo"].isin(TITULOS)].copy()
    e["data"] = e["data"].dt.date.map(cal.ultimo_dia_util_do_mes)
    e["vencimento"] = e["vencimento"].dt.date
    return e[["data", "isin", "titulo", "vencimento", "quantidade_mil"]]


def _com_precos(cal):
    """Junta posicao, taxa e VNA, e calcula PU e DV linha a linha."""
    pos = _posicoes(cal)
    tx = _ler("taxa_por_papel", parse_dates=["data"])
    tx["data"] = tx["data"].dt.date
    vn = _ler("vna", parse_dates=["data"])
    vn["data"] = vn["data"].dt.date
    vna_por = {(r.data, r.indice): r.vna for r in vn.itertuples(index=False)}

    df = pos.merge(tx[["data", "isin", "taxa_pct"]], on=["data", "isin"], how="left")
    df["vna"] = [
        vna_por.get((d, _INDICE_DO_TITULO[t])) if t in _INDICE_DO_TITULO else None
        for d, t in zip(df["data"], df["titulo"])
    ]

    pus, dvs = [], []
    for r in df.itertuples(index=False):
        precisa_vna = r.titulo in _INDICE_DO_TITULO
        if pd.isna(r.taxa_pct) or (precisa_vna and r.vna is None):
            pus.append(None)
            dvs.append(None)
            continue
        taxa = r.taxa_pct / 100.0
        pus.append(precificacao.pu(cal, r.titulo, r.data, r.vencimento, taxa, r.vna))
        dvs.append(precificacao.dv(cal, r.titulo, r.data, r.vencimento, taxa, r.vna))
    df["pu"] = pus
    df["dv_unitario"] = dvs
    return df


def painel():
    """Uma linha por papel e fim de mes, com insumos e resultado."""
    cal = calendario.padrao()
    df = _com_precos(cal)
    df["financeiro_calculado_milhoes"] = df["pu"] * df["quantidade_mil"] / 1000
    df["dv_posicao_milhoes"] = df["dv_unitario"] * df["quantidade_mil"] / 1000
    return df[_COLUNAS].sort_values(["data", "titulo", "vencimento"]).reset_index(drop=True)


def gravar_painel():
    config.PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    df = painel()
    saida = config.PROCESSED_DIR / "dv_por_papel.csv"
    df.to_csv(saida, index=False, encoding="utf-8")
    print(f"gravado: {saida} ({len(df)} linhas)")
```

```python
HORIZONTES = {"1du": 1, "5du": 5, "21du": 21}

_COLUNAS_DECAY = [
    "data_base", "horizonte", "data_alvo", "isin", "titulo",
    "venceu_no_caminho", "dv_base", "dv_alvo", "decay",
]


def _decay_de(cal, linhas, data_base, data_alvo, rotulo):
    """Reprecifica cada papel na data-alvo, com taxa e VNA constantes.

    Conta B da spec: so o efeito da passagem do tempo. Papel que vence no
    caminho recebe dv_alvo zero -- ele existia e deixou de existir, o que
    e informacao, nao ausencia -- e fica marcado para nao se confundir
    com queda de risco.
    """
    saida = []
    for r in linhas.itertuples(index=False):
        venceu = cal.ajustar_vencimento(r.vencimento) <= data_alvo
        if venceu:
            alvo = 0.0
        elif pd.isna(r.taxa_pct) or pd.isna(r.dv_unitario):
            alvo = None
        else:
            unitario = precificacao.dv(
                cal, r.titulo, data_alvo, r.vencimento, r.taxa_pct / 100.0, r.vna
            )
            alvo = unitario * r.quantidade_mil / 1000
        base = r.dv_posicao_milhoes
        decaimento = None if (alvo is None or pd.isna(base)) else alvo - base
        saida.append((data_base, rotulo, data_alvo, r.isin, r.titulo,
                      venceu, base, alvo, decaimento))
    return saida


def decay(horizontes=None):
    """Decay a taxa constante, por papel, nos horizontes pedidos."""
    horizontes = horizontes or HORIZONTES
    cal = calendario.padrao()
    p = painel()
    p = p[p["titulo"] != "LFT"]           # LFT nao tem DV no projeto

    linhas = []
    for data_base, grupo in p.groupby("data", sort=True):
        for rotulo, passos in horizontes.items():
            alvo = cal.mover(data_base, passos)
            linhas += _decay_de(cal, grupo, data_base, alvo, rotulo)
    return pd.DataFrame(linhas, columns=_COLUNAS_DECAY).sort_values(
        ["data_base", "horizonte", "titulo", "isin"]
    ).reset_index(drop=True)


def gravar_decay():
    config.PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    df = decay()
    saida = config.PROCESSED_DIR / "decay_por_papel.csv"
    df.to_csv(saida, index=False, encoding="utf-8")
    print(f"gravado: {saida} ({len(df)} linhas)")
```

O `painel()` precisa devolver também `vna` e `taxa_pct` para o decay reprecificar — já devolve. Note que `_decay_de` usa `r.vna`, `r.taxa_pct`, `r.dv_unitario`, `r.quantidade_mil` e `r.dv_posicao_milhoes`, todos presentes em `_COLUNAS`.

```python
def pontual(data_alvo, data_base=None):
    """Decompoe a queda de DV entre duas datas.

    Responde a pergunta do dia a dia: da posicao de hoje, quanto do DV
    some ate a data-alvo, e quanto disso e vencimento em vez de encurtar.
    """
    cal = calendario.padrao()
    p = painel()
    p = p[p["titulo"] != "LFT"]

    if data_base is None:
        data_base = max(p["data"])
    if data_alvo <= data_base:
        raise ValueError(
            f"a data-alvo ({data_alvo}) precisa ser posterior a data-base "
            f"({data_base})"
        )

    grupo = p[p["data"] == data_base]
    linhas = _decay_de(cal, grupo, data_base, data_alvo, "pontual")
    df = pd.DataFrame(linhas, columns=_COLUNAS_DECAY)

    vence = df[df["venceu_no_caminho"]]
    vive = df[~df["venceu_no_caminho"]]
    resumo = {
        "data_base": data_base,
        "data_alvo": data_alvo,
        "dv_base": df["dv_base"].sum(),
        "dv_que_vence": -vence["dv_base"].sum(),
        "decay_sobreviventes": vive["decay"].sum(),
        "dv_alvo": df["dv_alvo"].sum(),
    }
    resumo["por_titulo"] = (
        df.groupby("titulo")
          .agg(dv_base=("dv_base", "sum"), dv_alvo=("dv_alvo", "sum"),
               papeis=("isin", "nunique"),
               vencendo=("venceu_no_caminho", "sum"))
          .reset_index()
    )
    return resumo


def _formatar(r):
    linhas = [
        f"posicao em {r['data_base']}, projetada para {r['data_alvo']}",
        "",
        f"  DV na data-base           {r['dv_base']:14,.2f}",
        f"  (-) DV que vence          {r['dv_que_vence']:14,.2f}",
        f"  (-) decay dos que vivem   {r['decay_sobreviventes']:14,.2f}",
        f"  DV na data-alvo           {r['dv_alvo']:14,.2f}",
        "",
        "valores em R$ milhoes por bp; negativo = mercado perde na alta de taxa",
        "",
        r["por_titulo"].to_string(index=False),
    ]
    return "\n".join(linhas)


def main(argumentos=None):
    import argparse
    from datetime import datetime

    analisador = argparse.ArgumentParser(
        description="Decay do DV01 ate uma data-alvo. Requer PYTHONPATH=src."
    )
    analisador.add_argument("--alvo", required=True,
                            help="data-alvo, no formato DD/MM/AAAA")
    analisador.add_argument("--base", default=None,
                            help="data-base; o padrao e o ultimo mes do painel")
    analisador.add_argument("--figura", default=None,
                            help="caminho para gravar o grafico (opcional)")
    opcoes = analisador.parse_args(argumentos)

    ler = lambda s: datetime.strptime(s, "%d/%m/%Y").date()
    r = pontual(ler(opcoes.alvo), ler(opcoes.base) if opcoes.base else None)
    print(_formatar(r))
    if opcoes.figura:
        from . import figuras
        figuras.grafico_pontual(r, opcoes.figura)
        print(f"\nfigura: {opcoes.figura}")


if __name__ == "__main__":
    main()
```

**Contexto:** esta é a **Conta A** da spec, e ela tem duas metades com convenções de posição diferentes. Ler a §4 da spec antes de começar.

**O resultado em dinheiro é sobre a posição congelada no início do período.** O papel emitido no dia 20 não deu lucro nem prejuízo a quem estava posicionado no dia 1º. Então: pega a quantidade de `data_ini`, e reprecifica com o PU de `data_fim`.

`resultado_milhoes = (pu_fim − pu_ini) × quantidade_mil_ini / 1000`

**Papel que vence dentro do período é marcado, não somado junto** — mesma razão do decay. Para ele, `pu_fim` fica **vazio**: não sabemos a que preço o dinheiro foi reinvestido, e inventar uma hipótese de reinvestimento aqui seria embutir uma decisão de análise dentro da camada de dados. **A variação do DV é sobre o estoque real de cada data**, não sobre a posição congelada — ela responde "quanto risco o mercado passou a carregar", e emissão e resgate fazem parte da resposta. Como isso é uma agregação simples do painel, **não vira tabela**: é a função `variacao_de_dv()`, calculada na hora, coerente com a regra de não persistir derivado.

```python
_COLUNAS_RESULTADO = [
    "data_ini", "data_fim", "isin", "titulo", "venceu_no_periodo",
    "quantidade_mil_ini", "pu_ini", "pu_fim", "resultado_milhoes",
]


def resultado_mensal():
    """Conta A: resultado em dinheiro sobre a posicao congelada.

    A posicao e a do inicio do periodo, reprecificada com o PU do fim: o
    papel emitido no dia 20 nao deu lucro nem prejuizo a quem estava
    posicionado no dia 1o.

    Papel que vence dentro do periodo fica marcado e com pu_fim vazio. Nao
    sabemos a que preco o dinheiro foi reinvestido, e arbitrar uma hipotese
    de reinvestimento aqui embutiria decisao de analise na camada de dados.
    """
    cal = calendario.padrao()
    p = painel()
    p = p[p["titulo"] != "LFT"]

    datas = sorted(p["data"].unique())
    por_data = {d: g.set_index("isin") for d, g in p.groupby("data")}

    linhas = []
    for ini, fim in zip(datas, datas[1:]):
        antes, depois = por_data[ini], por_data[fim]
        for isin, r in antes.iterrows():
            venceu = cal.ajustar_vencimento(r["vencimento"]) <= fim
            pu_fim = None
            if not venceu and isin in depois.index:
                pu_fim = depois.loc[isin, "pu"]
                if pd.isna(pu_fim):
                    pu_fim = None
            resultado = None
            if pu_fim is not None and not pd.isna(r["pu"]):
                resultado = (pu_fim - r["pu"]) * r["quantidade_mil"] / 1000
            linhas.append((ini, fim, isin, r["titulo"], venceu,
                           r["quantidade_mil"], r["pu"], pu_fim, resultado))

    return pd.DataFrame(linhas, columns=_COLUNAS_RESULTADO).sort_values(
        ["data_fim", "titulo", "isin"]
    ).reset_index(drop=True)


def variacao_de_dv():
    """Conta A, outra metade: variacao do DV sobre o estoque REAL.

    Diferente do resultado, aqui a posicao nao e congelada -- emissao e
    resgate fazem parte da resposta a pergunta "quanto risco o mercado
    passou a carregar".

    Nao vira tabela: e agregacao simples do painel, e o projeto nao
    persiste derivado.
    """
    p = painel()
    p = p[(p["titulo"] != "LFT") & p["dv_posicao_milhoes"].notna()]
    por = (p.groupby(["data", "titulo"])["dv_posicao_milhoes"].sum()
             .reset_index().rename(columns={"dv_posicao_milhoes": "dv_milhoes"}))
    por = por.sort_values(["titulo", "data"])
    por["variacao_milhoes"] = por.groupby("titulo")["dv_milhoes"].diff()
    return por.reset_index(drop=True)


def gravar_resultado():
    config.PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    df = resultado_mensal()
    saida = config.PROCESSED_DIR / "resultado_mensal.csv"
    df.to_csv(saida, index=False, encoding="utf-8")
    print(f"gravado: {saida} ({len(df)} linhas)")
```
